# Quickstart

> [!NOTE]
> Gradle does not generate the project folder, while Maven does.


Example of Gradle init command:

```bash
gradle init \
  --type java-application \
  --dsl kotlin \
  --project-name kanban-sync \
  --package com.perilousbooklet.kanban-sync \
  --test-framework junit \
  --use-defaults
```
